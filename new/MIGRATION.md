# Dropped on purpose

- `networking.networkmanager.plugins = [pkgs.networkmanager-openvpn]` -> Not used anymore
- `programs.dconf` -> Never used
- `services.pipewire.wireplumber` -> Never used
- `environment.pathsToLink = ["/libexec"]` -> I don't know what this was for
- `gaming` aspect only needed on `alpha`
- `stateVersion` was updated on purpose, for NixOS (`system.stateVersion`) and Home-Manager (`home.stateVersion`)
  - Through it, docker's `live-restore` changed from `true` to `false`
- `xdg.portal.config.common.default` is now `gtk` as this is the desired value
  - Sway prefers `wlr` and falls back to `gtk` (`xdg.portal.config.sway.preferred`)
- `hardware.cpu.*.updateMicrocode` changed on purpose, the TODOs mark for later comparison against the original results
- `nixPath` changes was done on purpose as the original snippet didn't work
- Registry and `nixPath` entries use the kebab-case input names (e.g. `nixpkgs-stable` instead of `nixpkgsStable`)
- `networking.useDHCP` is true by default and therefore omitted from now on
- `docker` was dropped on `alpha` as it was never used
- `docker` no longer starts on boot (`enableOnBoot = false`), all hosts are desktops and containers are started on demand
- `mdadm` / `boot.swraid` was only enabled implicitly by the old `stateVersion` and no host uses software RAID
- `homeConfigurations.hiq` is gone, epsilon configures the work setup of `max` through the embedded Home-Manager instead
- The standalone `home-manager` CLI is no longer installed on NixOS hosts, as `nh os switch` applies Home-Manager as well
- `firmware` now enables `hardware.enableAllFirmware` and `services.fwupd` on top of the redistributable firmware the old hosts had, to support more devices and get firmware updates
- LibreOffice is the default `libreoffice` package instead of `libreoffice-qt6-fresh`
- The homeserver mounts additionally set `iocharset=utf8`
- `git-crypt` is installed system-wide on every host instead of through Home-Manager on desktops, so it is available before the first switch
- `librewolf` is gone, it was never imported
- The `nixpkgs-small` and `nixpkgs-stable-small` inputs are gone, they were never used
- Brightness keys in sway use `brightnessctl`, as `light` was removed from nixpkgs
- The waybar launcher lost its left and middle click actions, `rofi2` and `default_wall` don't exist
- The `alpha.lan` SSH match block moved from the `ssh` aspect into epsilon, the only host using it
